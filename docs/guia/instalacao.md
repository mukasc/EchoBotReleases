# Guia de Instalação (.exe)

A instalação do **EchoBot** foi projetada para ser direta e rápida para mestres e jogadores no Windows.

---

## 📥 Passo 1: Download da Versão Oficial

1. Acesse a página de lançamentos no GitHub: [Releases Oficiais do EchoBot](https://github.com/mukasc/EchoBot/releases).
2. Localize a versão mais recente com a tag **`Latest`**.
3. Na seção de **Assets**, baixe o arquivo executável:
   * `EchoBot-Setup-vX.X.X.exe` (ou pacote `.zip` portátil).

---

## 🛠️ Passo 2: Executando o Instalador

1. Dê um duplo clique no arquivo `.exe` baixado.
2. Caso o Windows SmartScreen exiba o aviso *"O Windows protegeu o seu computador"*, clique em:
   * **Mais informações** ➔ **Executar assim mesmo**.
3. Siga as instruções do assistente de instalação escolhendo o diretório de sua preferência.
4. Ao final, marque a opção para iniciar o **EchoBot**.

---

## 🛡️ Passo 3: Verificação de Permissões
* **Microfone:** Na primeira execução, permita que o aplicativo acesse o microfone do Windows nas configurações de privacidade.
* **Firewall:** Se solicitado pelo Firewall do Windows, permita o acesso em redes privadas para habilitar a comunicação local com o portal web e integrações com o Foundry VTT.
